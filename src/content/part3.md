# Data & Notebooks

Use these notebooks to investigate the methods introduced in the chapters. Each notebook specifies its data and software requirements; some of the original course applications require separately obtained datasets.

For a starting point that needs no external data or Google Drive setup, use the [NNA self-study notebook](notebooks/lab-05-nna-self-study.ipynb). It includes synthetic point patterns, a fixed-window Monte Carlo comparison, and an optional input for your own projected-coordinate CSV. Read the [NNA section](chapter_4/sec_04-03-Nearest-Neighbor-Analysis.md) alongside it.


For a real-data introduction to areal patterns, use the [autocorrelation self-study notebook](notebooks/lab-08-autocorrelation-self-study.ipynb) alongside [Autocorrelation & Spatial Autocorrelation](chapter_6/sec_06-01-Spatial-Autocorrelation.md). It explores 2022 household incomes in 11 areas around KL, provides observed and permuted maps, and distinguishes map interpretation from statistical inference. In this repository it uses an attributed source snapshot; standalone use can retrieve the official sources.
